01

Course context

The setup

Two-link rigid manipulator in a vertical plane. Joint 1 (lower) driven by a DC motor. Joint 2 (upper) free to rotate. Both links can rotate the full 360°.

Control objective

  1. θ₁ tracks a specified reference trajectory (zero steady-state error)
  2. θ₂ stabilised at upright position — the unstable equilibrium (θ₂ = 180°)

Easier start: both links down, damp the swing. Harder: swing-up + balance.

Assessment

Technical report (max 30 pages) + oral exam — equal weight.

Angle convention

θ₁ = 0, θ₂ = 0 → both links straight down (stable eq.)
θ₂ = ±180° → upper link straight up (unstable eq.)
Raw sensor zero ≈ 85° — bias subtraction gives down = 0.
θ₂ is relative (angle between arms); inertial angle of arm 2 = θ₁ + θ₂.

Input / output

Input: u ∈ [−1, +1] (normalised; +1 = max CW, −1 = max CCW)
Outputs: θ₁, θ₂ in degrees (in simout); radians inside ODE.

02

Equations of motion

Lagrangian derivation. Two degrees of freedom: θ₁ (arm 1 angle) and θ₂ (arm 2 angle relative to arm 1 extension). Point-mass assumption A1: arm 1 is a uniform rod (J₁ = m₁l₁²/3), arm 2's mass m₂ is concentrated at the tip.

Kinematics

CoM arm 1: \( (l_{c1}\sin\theta_1,\; -l_{c1}\cos\theta_1) \). Tip of arm 1 (joint 2): \( (l_1\sin\theta_1,\; -l_1\cos\theta_1) \). Ball tip:

Ball position
\[ x_{c2} = l_1\sin\theta_1 + l_2\sin(\theta_1+\theta_2), \qquad y_{c2} = -l_1\cos\theta_1 - l_2\cos(\theta_1+\theta_2) \]

Motor model

Joint 1 torque (back-EMF included)
\[ \tau = k_m u - k_b \dot\theta_1 \]
Code note
Back-EMF tau = km*u - kb*dth1 is now active in rhs(1) of rotpen_ode.m (Stage 1 fix). p.kb is a pre-ID placeholder — identify from arm-1 free-decay before relying on simulation accuracy.

Mass matrix M(θ₂)

Inertia matrix — 2×2, function of θ₂ only
\[ M(\theta_2) = \begin{pmatrix} J_1 + m_2\bigl(l_1^2 + l_2^2 + 2l_1 l_2\cos\theta_2\bigr) & m_2\bigl(l_2^2 + l_1 l_2\cos\theta_2\bigr) \\ m_2\bigl(l_2^2 + l_1 l_2\cos\theta_2\bigr) & m_2 l_2^2 \end{pmatrix} \]

where \(J_1 = \tfrac{1}{3}m_1 l_1^2\). Off-diagonal coupling = \(m_2 l_1 l_2 \cos\theta_2\) — disappears at θ₂ = ±90°.

Right-hand side

Let \( h = m_2 l_1 l_2 \sin\theta_2 \) (Coriolis prefactor).

Coriolis + gravity + damping + input
\[ \mathrm{rhs}_1 = \tau - c_1\dot\theta_1 + h\bigl(2\dot\theta_1\dot\theta_2 + \dot\theta_2^2\bigr) - \bigl(m_1 l_{c1} + m_2 l_1\bigr)g\sin\theta_1 - m_2 g l_2\sin(\theta_1+\theta_2) \] \[ \mathrm{rhs}_2 = -c_2\dot\theta_2 - h\dot\theta_1^2 - m_2 g l_2\sin(\theta_1+\theta_2) \]

Solve for accelerations

State-space acceleration step
\[ \begin{pmatrix}\ddot\theta_1 \\ \ddot\theta_2\end{pmatrix} = M^{-1}(\theta_2)\;\mathrm{rhs} \]

MATLAB: ddq = M \ rhs; — never invert M explicitly.

03

Modelling assumptions

A1 – A5
A1 — Point mass
Arm 2 massless; m₂ concentrated at tip only. J₁ = m₁l₁²/3 for uniform arm 1 rod.
Revisit if: l_eff ≪ l₂ physically (distributed mass shifts effective length — already evident: 0.0868 vs 0.10 m).
A2 — Stiff arm 1
Reaction forces from arm 2 onto arm 1 negligible. Full coupling kept in M for accuracy; off-diagonal can be dropped as a simplification after hardware validation.
Revisit if: arm 1 shows unexpected oscillations from arm 2 motion.
A3 — Simplified motor
τ = kmu − kbθ̇₁. Back-EMF included; inductance and higher-order dynamics ignored.
Revisit if: closed-loop bandwidth is unexpectedly limited at high speeds.
A4 — Viscous damping
Friction modelled as c·θ̇. Real joints likely have Coulomb + stiction too. Deadzone nonlinearity is a practical first proxy.
Revisit if: system ID fit is poor near zero velocity (residuals show stiction plateau).
A5 — Sensor bias
Raw hardware has ~85° offset per sensor. p.bias_th1 / p.bias_th2 in pendulum_params.m. Values recorded in hwinit.m per session. run_sim.m adds them so sim output matches raw hardware format.
Revisit if: calibration is done freshly each session — values may drift.

System ID workflow & observations

Workflow (lecture 2)

Simulink → To Workspace → iddata + idgrey → greyest → validate (held-out data)

greyest: grey-box parameter estimator; takes first-principles model structure, optimises parameters from data. Needs good initial guesses — use physical measurements where possible.

Identifiable composites

For a single swinging beam: a = mgl/I (from natural frequency), b = 1/I (from step/impulse response amplitude). Both equilibria give the same |A₂₁| — identify from stable, validate at unstable.

Input signal

Spikes or block inputs have broad power spectral density — excite wide frequency range. Multisine also valid. Cover DC to ω₂ = √(g/l₂) ≈ 9.9 rad/s minimum.

Motor frequency response (observed on hardware)

  • ω = 0.1 rad/s (T ≈ 63 s): arm swings one direction for almost full 15 s run — near DC step
  • ω = 5 rad/s (T ≈ 1.3 s): arm oscillates with reduced amplitude and slower-looking motion
  • Interpretation: motor + arm = low-pass filter. Inertia limits response; possibly back-EMF (A3) at higher speeds.

Friction options

  1. Viscous damping — c·θ̇ (our current A4)
  2. Deadzone nonlinearity — proxy for stiction: input has no effect until threshold. Practical first approximation.
  3. Unmodelled disturbance — rely on integral action in controller
Validation rule
Always validate on a held-out dataset. This is a course requirement — not optional.
